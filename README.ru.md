# AI Countdown

AI Countdown — открытый исследовательский прототип о том, какую работу AI уже берёт на себя.

[English version](README.md) · Русская версия

Сайт: [ai.ffnwz.lat](https://ai.ffnwz.lat)

## Что измеряет проект

На главной странице есть три направления:

- **Code** — участие AI-агентов в публичной разработке;
- **Work** — рабочие задачи и процессы;
- **Life** — повседневные задачи.

Это не точный мировой процент замещения. Источники имеют разные знаменатели, периоды и уровень доказательности, поэтому каждый сигнал хранится отдельно.

## Архитектура

- `server.js` — Node.js backend, API, кэширование и фоновые анализы;
- `app.js` — интерфейс, локализация, анимации и экспорт карточек;
- `data/` — редакционные источники, классификаторы и локальные данные;
- MongoDB используется для production-истории, JSON-файлы — fallback для standalone-запуска;
- GitHub API используется только на backend, токен никогда не передаётся в браузер.

## Анализ репозитория

Пользователь может отправить публичный GitHub-репозиторий. Backend:

1. сохраняет репозиторий и историю замеров;
2. анализирует до 300 коммитов в первом ответе;
3. продолжает остальную публичную историю в фоне;
4. распознаёт AI-агентов по публичным аккаунтам, email и `Co-Authored-By`;
5. показывает вклад агентов и остальных контрибьюторов по изменённым строкам;
6. повторно использует кэш не чаще одного анализа в сутки.

Если агент указан в `Co-Authored-By`, весь коммит относится к агенту, потому что GitHub не даёт разбивку строк между соавторами.

### Top 3 repositories

Топ-3 сортируется по взвешенному баллу:

```text
leaderboard score = AI changed lines × min(1, total changed lines / 10,000)
```

`Total changed lines` — additions плюс deletions в обработанной истории. Это не количество уникальных строк, оставшихся в текущем HEAD. Поправка не даёт небольшому репозиторию с 100% AI-вкладом автоматически обойти крупный проект.

## API

- `GET /api/combined-snapshot` — объединённый снимок для главного индекса;
- `GET /api/metric-series` — временной ряд Code, Work, Life и Overall;
- `GET /api/repository-analyses` — сохранённые анализы и Top 3;
- `GET /api/repository-analysis?repo=...` — анализ публичного репозитория;
- `POST /api/repository-analysis` — запуск анализа;
- `POST /api/contributor-analysis` — анализ собственных репозиториев контрибьютора;
- `GET /api/source-feeds` — внешние источники и их freshness.

## Локальный запуск

Требуется Node.js 20+.

```powershell
npm start
```

После запуска откройте `http://127.0.0.1:8765/`.

Создайте `.env` на основе `.env.example`. Основная переменная GitHub:

```env
GITHUB_FFNWZ_API_TOKEN=github_pat_...
```

Нужен fine-grained token с минимальными правами. Секреты, `.env`, локальные кэши, lock-файлы и `deploy.local.md` не должны попадать в Git.

## Ограничения

Code измеряет публичный сигнал участия AI, а не весь мировой код. Work и Life пока используют прототипные значения. Statements компаний, surveys, occupational exposure и AI-authorship не складываются в один процент без общей единицы измерения.

Проект предназначен для прозрачного наблюдения за источниками и ограничениями, а не для атрибуции авторства каждой строки или доказательства AGI/ASI.
