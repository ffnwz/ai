- внутренняя медиана по репозиториям: **28,5%**;

Значение 34,2% — взвешенный публичный attestation-сигнал, а не буквальная доля каждой строки кода в мире.

Собственные анализы AI Countdown хранятся отдельно. Каждый репозиторий даёт один голос в сопоставимом расчёте, а значение, взвешенное по строкам, сохраняется как контекст.

## Работа и Жизнь

Работа объединяет голос прототипа и оценки профессий медианой. Жизнь объединяет голос прототипа и частотно-временную медиану повторяющихся бытовых задач. Заявления компаний, опросы разработчиков, экспозиция профессий и workforce-наблюдения сохраняются с исходными знаменателями и напрямую не усредняются.

Среди supporting-наблюдений есть использование AI-инструментов, заявленная генерация кода, опросы разработчиков и потенциал автоматизации профессий. Они измеряют разные вещи и не превращаются автоматически в долю делегирования.

## Вспомогательные сигналы

- **Slop Score** — отдельная эвристика, она не смешивается с процентом AI Code Radar.
- **Bot Commits** и `github_explosion` описывают публичную активность AI-коммитов, а не точное число уникальных проектов.
- **GitHub AI Contributors** дают нижнюю границу, потому что публичный поиск и атрибуция неполны.
- **OSSInsight** — справочный слой публичной активности GitHub, а не глобальный источник AI-атрибуции.
- Для коммитов действует временная последовательность: распознанный коммит с агентом включает его для человека, три разных дня без агента исчерпывают последовательность, а другой распознанный агент сразу переключает её.

## Ограничения

- Code видит публичные AI-маркеры и может не заметить AI под обычными человеческими аккаунтами.
- `Co-Authored-By` даёт атрибуцию на уровне коммита; GitHub не показывает разбивку строк между авторами.
- Work и Life описывают возможности AI, а не фактическое внедрение в каждом доме или компании; частотность бытовых задач пока задана прозрачными редакционными предпосылками.
- Отчёты компаний, опросы, увольнения и экспозицию профессий нельзя объединять без явной общей методологии.
